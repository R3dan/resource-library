# Resource Library

Given this as the database schema, I want a frontend for it. It should have the following abilities: (1) Display any individual reasource (book, video or article), (2) Create any reasource, (3) Display them in a list that is filterable (ideally able to change between cards and standard list). Each reasource should have its own page, with filters stored in the query parameters. Use plain react + libraries. dont worry about the backend
